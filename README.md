# 무엇이든 뚝딱 — AI 창작 스튜디오

만들고 싶은 게임, 이야기, 시뮬레이션, 인터랙티브 아트, 작은 도구를 말로 설명하고, 브라우저에서 직접 실행하며 다듬는 개인 창작 도구입니다. AI 모드에서는 OpenAI API가 **실행 가능한 HTML·CSS·JavaScript를 생성**하며, 수정 요청도 현재 작품의 코드를 바탕으로 처리합니다.

**실제 AI 제작에는 전체 버전 실행과 OpenAI API 키가 필요합니다.** 설치 없이 여는 `preview/index.html`은 플레이 가능한 예제를 체험하는 파일이며 AI에 연결된 버전이 아닙니다. AI 실패를 예제 생성으로 바꿔 성공한 것처럼 표시하지 않습니다.

## 실제 AI로 처음 만들기

1. GitHub에서 **`codex-ddukttak-preview` 브랜치**를 선택하고 **Code → Download ZIP**으로 내려받아 압축을 풉니다.
2. [Node.js 공식 사이트](https://nodejs.org/)에서 **Node.js 24 LTS**를 설치합니다. 최소 지원 버전은 22입니다.
3. Windows는 **`tools/start-windows.cmd`**를 실행합니다. macOS는 프로젝트 폴더의 터미널에서 **`bash tools/start-macos.command`**를 실행합니다.
4. 터미널에 표시되는 개발 주소를 브라우저에서 엽니다. 기본값은 `http://localhost:5173`이며, 내 컴퓨터에서 사용하는 주소입니다.
5. 창작 스튜디오에서 **OpenAI 연결하기**를 열어 본인의 OpenAI API 키와 모델을 입력하고 **연결하고 응답 확인**을 누릅니다. 기본 모델은 `gpt-4.1`이며 사용할 수 있는 모델로 바꿀 수 있습니다.
6. 작품 종류와 원하는 내용을 적고 **AI로 새로 만들기 → AI로 작품 만들기**로 생성합니다. 생성된 화면을 직접 플레이하고, 바꾸고 싶은 점을 **AI 대화**에서 요청합니다.

키는 채팅에 보내지 말고 실행한 앱의 연결 화면에 직접 입력하세요. OpenAI API 이용 권한·결제가 필요하며 ChatGPT 구독과 API 요금은 별개입니다. 연결 테스트와 생성·수정·오류 수정 요청에도 API 비용이 발생할 수 있습니다.

설치가 처음이라면 [파일 받기부터 실행까지](docs/VIEW_RESULT.md)를 따라 하세요. 서버 없이 먼저 둘러보려면 ZIP의 **`preview/index.html`**을 Chrome 또는 Edge로 열어 **예시로 체험하기 → 선택한 예시 열기**를 선택할 수 있습니다.

## 무엇을 만들 수 있나요?

| 종류 | 요청 예시 |
| --- | --- |
| 게임 | “좌우로 움직이며 별을 모으고, 장애물에 닿으면 끝나는 우주 게임. 점수와 다시 시작 버튼도 넣어줘.” |
| 선택형 이야기 | “탐정이 된 고양이 이야기. 선택에 따라 세 가지 결말로 이어지게 해줘.” |
| 시뮬레이션 | “공을 던지는 각도와 속도를 슬라이더로 바꾸며 궤적을 보는 실험실.” |
| 인터랙티브 아트 | “마우스와 손가락을 따라 색 입자가 번지는 그림 도구.” |
| 작은 도구 | “공부 시간과 쉬는 시간을 정할 수 있는 집중 타이머.” |
| 웹사이트 | “작업물을 소개하고 탭으로 분류하는 포트폴리오.” |

결과물은 브라우저에서 실행되는 하나의 작품입니다. 단순 소개 페이지에 제한하지 않으며 게임 규칙, 상태 변화, 계산, 선택 분기 같은 동작을 코드로 만들 수 있습니다. 외부 라이브러리 다운로드나 외부 API 요청에 의존하지 않는 범위로 제작합니다.

네이티브 APK·iOS 앱 빌드, 앱스토어 등록, 실시간 멀티플레이 서버, 사용자 인증·공유 데이터베이스·실제 결제는 자동으로 구성하지 않습니다. 큰 작품은 먼저 작게 만들고 한 번에 하나씩 기능을 추가하는 편이 확인과 수정에 좋습니다.

## 예제 체험과 AI 제작의 차이

| | 예제 체험 | 실제 AI 제작 |
| --- | --- | --- |
| 실행 환경 | 내려받은 HTML 또는 전체 버전 | 전체 버전의 Node.js 서버 |
| 내용 | 미리 준비된 플레이 가능한 예제 | 요청을 해석해 새 실행 코드 생성 |
| API 키 | 필요 없음 | 본인의 OpenAI API 키 필요 |
| 대화형 코드 수정·AI 오류 수정 | 제공하지 않음 | 연결된 AI에 실제 요청 |
| 직접 설정·버전 복원·HTML 내려받기 | 사용 가능 | 사용 가능 |
| 작업 저장 | 체험 파일은 해당 브라우저 | 전체 버전은 서버의 `.data/works.json` |

예제 이름을 바꾸거나 난이도를 조절하는 것은 AI가 새 게임을 개발한 결과가 아닙니다. 예제와 AI 생성 작품은 화면의 출처 표시로 구분합니다.

## 만들면서 고치기

처음에는 핵심 동작부터 요청합니다. 실행해 본 뒤 다음처럼 하나씩 추가해 보세요.

```text
시작 화면에 조작 방법을 크게 보여줘.
별을 10개 모으면 다음 단계로 넘어가게 해줘.
휴대폰에서도 움직일 수 있도록 좌우 터치 버튼을 추가해줘.
게임이 끝나면 점수와 다시 시작 버튼을 보여줘.
이야기의 두 번째 선택지를 고르면 다른 결말이 나오게 해줘.
```

**빠른 설정**에서는 제목·포인트 색상·난이도 등을 바꿀 수 있습니다. 예제 게임은 난이도에 반응하며 AI 작품에서는 구현한 코드에 따라 달라집니다. 동작을 바꾸려면 AI 대화로도 요청할 수 있습니다. **코드** 탭에서는 HTML·CSS·JavaScript를 직접 편집할 수 있습니다. 수정할 때 버전이 남고, 이전 모습으로 복원해도 현재 작업은 기록에 보관됩니다.

미리보기에서 실행 오류가 감지되면 오류 내용을 확인하고 **AI로 이 오류 수정**을 요청할 수 있습니다. 한 번 누를 때 한 번 요청하며, 무제한 자동 재시도로 비용을 사용하지 않습니다. AI도 항상 완전한 결과를 보장하지 않으므로 수정 뒤 다시 플레이하세요. 요청 실패 시 마지막으로 저장된 작품과 버전은 유지됩니다.

## OpenAI 연결과 키 보관

### 화면에서 연결하기

전체 버전의 AI 연결 화면에서 키를 입력하고 연결 테스트를 실행합니다. 키는 테스트를 위해 로컬 서버로 전송되며 **브라우저 저장소·작품·버전·로그 파일에 저장하지 않습니다**. 성공한 화면 입력 키는 실행 중인 서버의 메모리에서만 사용하고 서버 재시작 시 사라집니다. 새로고침만으로 서버의 키가 삭제되지는 않습니다.

연결 해제는 화면에서 입력한 서버 메모리의 키를 해제합니다. 서버에 환경변수로 설정한 키가 있으면 그 설정은 남을 수 있습니다. 화면의 연결 출처와 상태를 확인하세요.

연결 테스트 성공은 해당 요청이 공급자에서 처리되었다는 뜻이며, 이후 모든 생성이나 요금·모델 권한을 보장하지 않습니다. 모델은 JSON Schema 기반 Structured Outputs를 지원해야 합니다. 직접 소유한 컴퓨터의 서버 또는 인증된 비공개 작업 공간에서만 키를 연결하세요.

### 서버 환경변수로 연결하기

`.env.example`을 참고해 프로젝트 루트의 `.env`에 키를 설정하고 서버를 다시 시작할 수도 있습니다. 기존 파일을 덮어쓰지 말고 필요한 항목만 추가하세요.

| 변수 | 용도 |
| --- | --- |
| `DDUK_AI_API_KEY` | 서버에서 사용할 본인의 OpenAI API 키 |
| `DDUK_AI_MODEL` | 사용할 모델. 기본값 `gpt-4.1` |
| `DDUK_AI_BASE_URL` | 기본값 `https://api.openai.com/v1` |

키를 Git 저장소·스크린샷·`VITE_` 환경변수·생성한 HTML에 넣지 마세요. AI 생성·수정 시에는 요청 문구와 현재 작품 코드가 공급자에게 전달되므로 작품 안에도 비밀값을 넣지 않습니다.

## 실행 명령

프로젝트 폴더에서 실행합니다.

```bash
npm ci
npm run dev
```

개발 화면은 기본 `5173`, API는 `3001` 포트를 사용합니다. 종료는 실행한 터미널에서 `Ctrl+C`입니다. 빌드한 화면과 API를 함께 사용하려면 다음 명령을 실행합니다.

```bash
npm run build
npm start
```

기본 주소는 `http://localhost:3001`입니다. 인증 없는 개인 작업 서버이므로 그대로 인터넷에 공개하지 마세요. 만든 작품은 **실행 파일 받기**로 HTML을 내려받아 별도로 사용할 수 있습니다. 공개·백업 절차는 [실행·공개 안내](docs/DEPLOYMENT.md)에 있습니다.

설치 없는 체험 파일을 다시 만들려면 `npm run build:portable`을 실행합니다. `artifacts/ddukttak-preview.html`에 화면·스타일·글꼴이 포함된 단일 파일이 생성됩니다. 이 파일을 빌드해도 OpenAI 키나 실행 중인 서버가 포함되지는 않습니다.

## 검증

```bash
npm test
npm run build
npm run test:e2e
```

자동 테스트는 예제의 실제 조작, 저장과 복원, 샌드박스 격리, API 실패 처리 등을 검사합니다. AI 응답을 대역으로 제공하는 테스트와 실제 OpenAI 연결은 구분해야 합니다. 본인의 키로 연결 테스트·생성·수정을 실행하기 전에는 실제 공급자 동작이 검증된 것으로 보지 않습니다.

브라우저 테스트에는 Chromium이 필요합니다. 시스템 `/usr/bin/chromium`이 없으면 `npx playwright install chromium`으로 설치할 수 있으며, 다른 실행 경로는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`로 지정합니다. 클라우드 브라우저가 `file://`를 차단할 때 다운로드 HTML의 바이트를 그대로 정적 HTTP 응답으로 제공해 검사합니다. 일반 컴퓨터에서의 파일 직접 열기는 해당 브라우저에서도 확인하세요.

## 구조와 데이터

```text
src/creative/       창작 스튜디오, 작품 규격, 예제, 격리 실행기
server/creative*    OpenAI 연결·생성·수정·오류 수정과 작품 API
.data/works.json   전체 버전의 작품·대화·버전 저장
src/App.tsx        기존 웹사이트 구성형 빌더
.data/workspace.json 기존 웹사이트 프로젝트 저장
preview/index.html 설치 없는 예제 체험 파일
tools/             Windows·macOS 실행 도우미
```

작품 코드는 부모 화면과 다른 출처의 iframe에서 실행하며 네트워크 접근을 막습니다. 호스트 앱의 쿠키·저장소에 접근하거나 네이티브 프로그램을 실행하는 방식이 아닙니다. 내려받은 작품도 외부 API·서버 기능이 자동 연결되지는 않습니다.

이전 웹사이트 구성형 빌더도 별도로 유지합니다. 왼쪽 아래 **기존 웹사이트 빌더**를 누르거나 주소에 `?studio=websites`를 붙여 엽니다. 자세한 기능과 폼·사진 편집 안내는 [웹사이트 빌더 안내](docs/WEBSITE_BUILDER.md)를 참고하세요.
