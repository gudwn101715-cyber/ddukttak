# 만든 결과를 직접 보는 방법

가장 간단한 방법은 **간편 실행 HTML 파일을 내려받아 여는 것**입니다. 전체 소스코드로 실행하려면 아래 두 번째 방법을 사용하세요.

이 안내에 나오는 파일은 다운로드할 수 있도록 제공된 경우에 사용할 수 있습니다. 다운로드 파일이 보이지 않거나 현재 화면에서 파일 받기를 지원하지 않으면, 다른 컴퓨터에서 열었다고 가정하지 말고 파일 전달이 가능한 방법부터 확인해야 합니다. 현재 인터넷 공개 주소가 발급되었다는 의미는 아닙니다.

## 방법 1. 설치 없이 간편 실행하기

1. 제공된 **`ddukttak-preview.html`** 파일을 컴퓨터에 저장합니다. 간편 실행 ZIP으로 제공되었다면 먼저 압축을 풀고 그 안의 **`index.html`**을 찾습니다.
2. 파일을 두 번 클릭해 Chrome, Edge 또는 Safari 등 일반 웹브라우저로 엽니다.
3. **새 프로젝트 만들기**를 눌러 이름과 용도를 적고, 분위기와 기능을 고릅니다.
4. 미리보기에서 버튼과 양식을 눌러 봅니다. **직접 수정**, **기능 관리**, **변경 기록**으로 원하는 모습까지 다듬을 수 있습니다.
5. **앱 파일 내려받기**로 만든 결과물을 별도 HTML로 보관합니다.

Node.js 설치, API 키, 서버 실행은 필요하지 않습니다. 파일이 텍스트 편집기로 열린다면 파일을 우클릭해 웹브라우저로 열기를 선택하세요. 회사나 클라우드에서 관리하는 브라우저는 로컬 HTML 열기가 제한될 수 있으므로, 개인 컴퓨터에서 열거나 아래의 정적 호스팅 방법을 사용할 수 있습니다.

### 간편 실행판의 저장과 기능

간편 실행판은 브라우저 안에서 템플릿과 규칙을 이용해 앱을 만들고 수정합니다. 실제 외부 AI를 호출하는 버전은 아닙니다. 지원하는 색상·문구 변경과 기능 추가는 바로 사용할 수 있으며, 지원하지 않는 요청은 안내가 표시됩니다.

프로젝트와 변경 기록은 **열어 둔 브라우저의 로컬 저장소**에 보관합니다. 같은 파일을 같은 브라우저에서 다시 열면 이어갈 수 있지만, 브라우저 정책에 따라 파일 저장소가 제한될 수 있습니다. 브라우저 데이터를 지우거나 시크릿 창을 닫거나 다른 기기로 옮기면 작업을 찾지 못할 수 있으니 필요한 결과물은 파일로 내려받아 두세요. 브라우저 저장 공간은 서버 백업과 다릅니다.

예약·문의·구독 양식은 입력과 확인을 체험하는 기능입니다. 운영자에게 전달되거나 실제 예약이 확정되는 것은 아닙니다. 간편 실행판에는 여러 사람의 응답 수집, 실제 AI 연결, 사용자 로그인, 클라우드 자동 배포가 포함되어 있지 않습니다.

## 방법 2. 전체 소스코드로 실행하기

이 방법은 서버에 프로젝트를 저장하고, 필요할 때 서버 전용 AI 키도 연결하고 싶은 경우에 사용합니다.

1. **`ddukttak-source.zip`**을 내려받아 압축을 모두 풉니다. ZIP 안에서 바로 실행하지 마세요.
2. [Node.js 공식 사이트](https://nodejs.org/)에서 **Node.js 24 LTS**를 설치합니다. Node.js 22 이상도 사용할 수 있습니다.
3. 아래에서 사용하는 운영체제의 방법을 따라 실행합니다. 처음 실행할 때는 인터넷으로 패키지를 설치하므로 잠시 기다립니다.

### Windows

압축을 푼 프로젝트 폴더의 **`tools` → `start-windows.cmd`**를 두 번 클릭합니다.

Node.js나 npm이 없으면 안내가 표시됩니다. 설치 후에는 창을 닫고 다시 실행하세요. 서버가 켜지면 브라우저 주소창에 **`http://localhost:5173`**을 입력합니다. 이것은 내 컴퓨터에서만 사용하는 개발 주소이며, 다른 사람에게 공유하는 인터넷 주소가 아닙니다.

### macOS

터미널을 열고 `cd `를 입력한 다음 압축을 푼 프로젝트 폴더를 터미널 창으로 끌어놓고 Enter를 누릅니다. 이어서 실행합니다.

```bash
bash tools/start-macos.command
```

서버가 켜지면 브라우저 주소창에 **`http://localhost:5173`**을 입력합니다. ZIP 압축 해제 과정에서 실행 권한이 바뀔 수 있으므로, 위 명령으로 실행하면 파일의 실행 권한에 의존하지 않습니다.

### 실행 중 알아두기

실행 창은 작업하는 동안 열어 두세요. 종료하려면 그 창에서 `Ctrl+C`를 누릅니다. 포트가 이미 사용 중이면 실행이 중단돼요. 이미 켜 둔 실행 창이 있는지 확인하고, 그 창을 이용하거나 먼저 종료한 뒤 다시 실행하세요.

시작 스크립트는 `node_modules`가 없을 때만 `npm ci`를 실행하고, 설치 캐시는 프로젝트의 `.npm-cache`에 보관합니다. 소스코드를 업데이트해 의존성이 바뀌었거나 설치를 다시 해야 한다면 프로젝트 폴더의 터미널에서 다음 명령을 실행하세요.

```bash
npm ci --cache .npm-cache
npm run dev
```

프로젝트는 서버의 `.data/workspace.json`에 저장됩니다. 소스 ZIP에는 작업 데이터와 `.env`, API 키가 포함되지 않습니다. 외부 AI는 기본 사용에 필요하지 않으며, 연결할 때만 [README의 AI 설정 안내](../README.md#ai-연결하기--선택-사항)를 따르세요.

전체 버전도 개인 작업 공간을 위한 개발 버전입니다. 인증 없는 서버를 그대로 인터넷에 공개하면 다른 사람이 프로젝트에 접근할 수 있으므로, 만든 정적 HTML을 별도로 공개하는 방법을 사용하세요.

## 다른 사람도 볼 수 있는 인터넷 주소가 필요하면

간편 실행판이나 생성한 앱의 HTML은 정적 호스팅에 올릴 수 있습니다.

1. 공개할 파일을 새 폴더에 넣고 파일명을 **`index.html`**로 정합니다.
2. 본인의 호스팅 계정으로 로그인합니다.
3. [Cloudflare Pages 직접 업로드](https://developers.cloudflare.com/pages/get-started/direct-upload/) 또는 [Netlify 수동 배포](https://docs.netlify.com/deploy/create-deploys/#deploy-manually) 절차에 따라 폴더를 올립니다.
4. 호스팅 서비스가 발급한 HTTPS 주소를 PC와 휴대전화에서 엽니다.

간편 실행판을 호스팅해도 각 방문자의 프로젝트는 각자의 브라우저에 저장되며 서로 공유되지 않습니다. 생성된 앱을 올려도 폼 응답이 자동으로 사업자에게 전송되지는 않습니다. 실제 운영을 위한 데이터 수신·로그인·AI 연결은 별도 연동이 필요합니다.

호스팅은 사용자의 계정에서 직접 진행해야 하며, 이 안내만으로 계정·도메인·공개 주소가 자동 생성되지는 않습니다. 자세한 결과물 공개와 백업 방법은 [실행·공개 안내](DEPLOYMENT.md)를 참고하세요.
