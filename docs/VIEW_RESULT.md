# 실제 AI로 만들기와 설치 없는 체험

**원하는 게임·창작물을 AI에게 새로 만들어 달라고 하려면 전체 버전을 실행하고 OpenAI를 연결하세요.** HTML 파일만 열어 체험하는 방식은 미리 준비된 예제를 플레이하는 경로입니다.

두 방법 모두 GitHub의 **`codex-ddukttak-preview` 브랜치**에서 **Code → Download ZIP**으로 파일을 받을 수 있습니다. 이 브랜치를 선택한 뒤 내려받아야 현재 제작 화면이 포함됩니다. 별도 `ddukttak-source.zip`을 받은 경우에도 전체 소스 경로를 사용할 수 있습니다.

## 방법 1. 전체 버전에서 실제 AI 사용하기

### 준비물

- Node.js 22 이상. 처음 설치한다면 [Node.js 공식 사이트](https://nodejs.org/)의 **24 LTS**를 권장합니다.
- 본인의 OpenAI API 키와 API 사용 권한·결제 설정. ChatGPT 구독과 API 이용 요금은 별개입니다.
- 처음 패키지를 설치하고 AI를 요청할 때 사용할 인터넷 연결.

API 키는 채팅에 보내지 말고 아래에서 실행할 앱의 연결 화면에 직접 입력하세요.

### Windows

1. 받은 ZIP의 압축을 모두 풉니다. ZIP 안에서 바로 실행하지 마세요.
2. 프로젝트 폴더의 **`tools` → `start-windows.cmd`**를 두 번 클릭합니다.
3. 처음 실행할 때 패키지가 설치됩니다. 오류 없이 개발 서버가 준비되면 브라우저에 **`http://localhost:5173`**을 입력합니다.

Node.js나 npm이 없으면 실행 창에 안내가 나옵니다. 설치 후 창을 닫고 다시 실행하세요.

### macOS

1. ZIP의 압축을 모두 풉니다.
2. 터미널에 `cd `를 입력하고 압축을 푼 프로젝트 폴더를 터미널 창으로 끌어놓은 다음 Enter를 누릅니다.
3. 다음 명령을 실행합니다.

```bash
bash tools/start-macos.command
```

개발 서버가 준비되면 브라우저에 **`http://localhost:5173`**을 입력합니다. ZIP에서 파일 실행 권한이 바뀌어도 위 명령으로 실행할 수 있습니다.

### OpenAI 연결하고 만들기

1. 창작 스튜디오에서 **OpenAI 연결하기**를 엽니다. 상단의 연결 상태 또는 편집 화면의 **AI 연결**을 눌러도 됩니다.
2. OpenAI API 키를 입력합니다. 모델은 기본 `gpt-4.1`이며 사용할 수 있는 모델로 바꿀 수 있습니다.
3. **연결하고 응답 확인**을 누르고 실제 응답 결과를 확인합니다. 연결 테스트에도 API 비용이 발생할 수 있습니다.
4. 게임·이야기·시뮬레이션·아트·도구 등 원하는 종류를 고르고 내용을 구체적으로 설명합니다.
5. **AI로 새로 만들기 → AI로 작품 만들기**로 생성한 뒤 플레이합니다. **AI 대화**에서 “목숨을 세 개로”, “선택지를 하나 더”, “터치 버튼을 크게”처럼 후속 수정도 요청할 수 있습니다.
6. 실행 오류가 보이면 내용을 확인하고 **AI로 이 오류 수정**을 한 번 요청한 뒤 다시 실행합니다.

화면에 입력한 키는 로컬 서버 메모리에서만 사용하고 작품 파일이나 브라우저 저장소에 저장하지 않습니다. 서버를 껐다 켜면 다시 연결해야 합니다. 서버의 `.env`에 키를 설정하는 방법도 있으며 [README의 연결 안내](../README.md#openai-연결과-키-보관)를 참고하세요.

실행 창은 작업 중 열어 두고, 종료할 때 `Ctrl+C`를 누릅니다. 안내된 주소는 **내 컴퓨터의 실행 주소**이며 인터넷 공개 주소가 아닙니다. 포트가 이미 사용 중이면 실제 터미널 출력을 확인하세요.

시작 스크립트는 `node_modules`가 없을 때만 패키지를 설치하고 `.npm-cache`에 설치 캐시를 보관합니다. 소스를 업데이트한 뒤 설치가 필요하면 프로젝트 폴더에서 직접 실행합니다.

```bash
npm ci --cache .npm-cache
npm run dev
```

전체 버전의 작품과 버전은 `.data/works.json`에 저장됩니다. 소스 ZIP에는 개인 작업 데이터·`.env`·API 키를 포함하지 않습니다.

## 방법 2. 설치 없이 예제 플레이하기

1. GitHub ZIP의 압축을 풀고 **`preview/index.html`**을 찾습니다. 별도로 제공된 **`ddukttak-preview.html`**도 같은 용도입니다.
2. 파일을 Chrome 또는 Edge 같은 일반 브라우저로 엽니다.
3. 게임·선택형 이야기·시뮬레이션·아트·도구를 고르고 **예시로 체험하기 → 선택한 예시 열기**를 누릅니다. 아래의 **예시 열기** 카드로도 바로 시작할 수 있습니다.
4. **빠른 설정**·**변경 기록**·**실행 파일 받기**를 사용할 수 있습니다.

Node.js나 API 키는 필요하지 않습니다. **예제 체험에서는 원하는 문장을 해석해 새로운 작품을 AI로 생성하거나 대화로 코드를 수정하지 않습니다.** 실제 AI 사용은 위의 전체 버전으로 진행해야 하며, 체험 파일에 키를 넣는 방식으로 연결하지 않습니다.

작업은 해당 브라우저의 저장소에 보관됩니다. 브라우저 데이터를 지우거나 다른 브라우저·기기로 옮기면 작업이 없을 수 있으므로 필요한 결과물은 내려받아 두세요. 시크릿 창이나 파일 저장소를 제한하는 브라우저에서는 저장이 유지되지 않을 수 있습니다.

파일이 텍스트 편집기로 열리면 우클릭해 웹브라우저로 열기를 선택하세요. 관리형 브라우저가 로컬 HTML을 차단하면 일반 개인 컴퓨터에서 열거나 정적 호스팅에 올릴 수 있습니다. 클라우드에서 파일을 직접 열 수 있다는 보장은 아닙니다.

## 만든 작품을 공유하려면

작품에서 **실행 파일 받기** 또는 **실행 안내 → HTML 실행 파일 받기**를 선택해 HTML을 받습니다. 받은 파일을 다른 컴퓨터에서 열어 직접 플레이할 수 있습니다. 내려받은 파일은 그때의 버전이며, 나중에 수정한 내용은 새로 내려받아야 합니다.

인터넷 주소가 필요하다면 파일명을 `index.html`로 정해 새 폴더에 넣고 본인의 호스팅 계정으로 업로드합니다.

- [Cloudflare Pages 직접 업로드](https://developers.cloudflare.com/pages/get-started/direct-upload/)
- [Netlify 수동 배포](https://docs.netlify.com/deploy/create-deploys/#deploy-manually)

호스팅 서비스가 발급한 HTTPS 주소를 PC와 휴대전화에서 확인하세요. 실제 API 키가 필요한 창작 서버를 그대로 공개하는 방식은 아닙니다. 정적 파일을 올려도 실제 AI·로그인·멀티플레이 서버·고객 응답 수집이 자동 연결되지는 않습니다. 자세한 실행·백업 안내는 [실행·공개 안내](DEPLOYMENT.md)에 있습니다.
