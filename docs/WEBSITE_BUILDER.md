# 기존 웹사이트 구성형 빌더 안내

새 기본 화면은 게임·이야기·시뮬레이션·아트·도구를 만드는 AI 창작 스튜디오입니다. 왼쪽 아래 **기존 웹사이트 빌더**를 누르거나 주소에 `?studio=websites`를 붙이면 기존 질문형 빌더를 엽니다. 검증된 구성 요소를 조합해 소개·예약 소개·포트폴리오·상품 소개 페이지를 만듭니다.

이 빌더의 AI는 정형화된 앱 구성을 편집합니다. 새 창작 스튜디오의 실제 HTML·CSS·JavaScript 생성과 처리 방식이 다릅니다. 설치 없는 체험 파일은 준비된 구성과 규칙으로 동작하고 외부 AI를 호출하지 않습니다.

## 기본 사용

1. **새 프로젝트 만들기** 또는 템플릿을 선택합니다.
2. 이름·소개·종류, 원하는 디자인, 기능을 고릅니다.
3. 미리보기에서 버튼·폼을 조작하고 모바일 크기도 확인합니다.
4. **직접 수정**에서 문구·배경·글꼴·모서리와 소개 영역을 바꿉니다. 소개 영역은 추가·삭제할 수 있습니다.
5. **기능 관리**에서 문의·예약·갤러리·FAQ·구독·후기를 추가하거나 뺍니다.
6. **변경 기록**으로 복원하거나 **실행 안내**에서 자동 점검·앱 파일 내려받기를 사용합니다.

중간 질문 답변과 단계는 브라우저에 임시 저장됩니다. 전체 버전의 완성 프로젝트는 `.data/workspace.json`에 저장하고, 설치 없는 체험판은 해당 브라우저에만 저장합니다.

## 사진·FAQ·후기 채우기

**기능 관리**에서 해당 기능을 켠 뒤 **직접 수정**의 세부 항목을 펼칩니다.

- **갤러리 사진과 설명 수정**: 최대 6개. 사진 제목·설명과 사진을 바꿉니다.
- **자주 묻는 질문 수정**: 최대 10개. 실제 서비스의 질문·답변을 적습니다.
- **고객 후기 수정**: 최대 6개. 실제 후기 내용과 공개 가능한 고객 이름을 적습니다.

사진은 한 장당 10MB 이하의 JPG·PNG·WebP를 올릴 수 있습니다. 브라우저에서 크기를 줄이고 JPEG로 변환해 HTML에도 포함합니다. HTTPS 사진 주소는 원본 서버와 인터넷 연결이 필요합니다.

예시 사진·문구·후기는 실제 서비스 내용으로 교체하세요. 실제 후기가 없다면 후기 기능을 꺼 둡니다. 이 빌더에서는 직접 작성한 상세 콘텐츠·사진을 AI 편집 시 보존하고 공급자에게 보내지 않습니다.

## 자연어 수정

기본 규칙 모드에서는 색상·제목·버튼 문구와 지원 기능을 바꿀 수 있습니다.

```text
테마를 파란색으로 바꿔 줘
제목을 '매일의 작은 쉼'으로 바꿔 줘
버튼 문구를 '수업 문의하기'로 바꿔 줘
자주 묻는 질문을 추가해 줘
갤러리를 삭제해 줘
```

지원하지 않는 요청은 적용되지 않았다는 안내가 나옵니다. 새로운 게임 동작이나 자유로운 코드가 필요하다면 새 창작 스튜디오에서 실제 AI 제작을 사용하세요. 기존 빌더의 외부 AI는 서버의 환경변수 설정을 사용합니다.

## 실제 운영 전에

예약·문의·구독 폼은 방문자 브라우저에 보관되는 체험용 기능입니다. 사업자에게 전송되거나 실제 예약이 확정되지 않습니다. 공유 응답 수집·메일 발송·결제는 별도 서비스 연동이 필요합니다.

자동 점검은 구성 유효성과 주요 설정을 확인하는 보조 기능이며 실제 고객 접수를 검증한 결과가 아닙니다. 직접 테스트한 뒤 HTML을 내려받아 공개하세요. 로컬 게시 경로는 해당 서버에 접근할 수 있는 환경에서만 열립니다.

전체 플랫폼은 아직 개인 작업 공간입니다. 소셜 로그인·사용자별 권한·관리형 데이터베이스·클라우드 자동 배포·공유 데이터 수신은 별도로 구현해야 합니다. 공개 방법과 백업은 [실행·공개 안내](DEPLOYMENT.md)를 참고하세요.
