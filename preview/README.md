# 설치 없이 작품 체험하기

`index.html`을 브라우저에서 열면 게임·선택형 이야기·물리 실험·대칭 드로잉·저축 계산기·포트폴리오의 **직접 실행하는 예시**를 볼 수 있습니다. ‘예시 열기’를 누르고 작품을 플레이해 보세요. 빠른 설정, 버전 복원, HTML 실행 파일 내려받기도 체험할 수 있습니다.

이 파일에는 AI 서버가 없습니다. 임의의 아이디어를 **실제 OpenAI로 생성·수정**하려면 전체 소스 폴더의 실행 도우미로 앱을 실행한 뒤 ‘OpenAI 연결하기’에서 API 키를 입력하고 ‘연결하고 응답 확인’을 눌러 주세요. 상세한 방법은 [결과 확인 안내](../docs/VIEW_RESULT.md)를 참고하세요. API 키는 채팅이나 Git 파일에 넣지 마세요.

작품은 브라우저 저장소에 기록되므로 실행 환경을 바꾸거나 브라우저 데이터를 지우기 전에 원본과 실행 파일을 내려받아 보관하세요. 체험판과 전체 앱의 기록은 별도입니다.

글꼴과 라이브러리 라이선스는 `THIRD_PARTY_NOTICES.txt`에 있습니다.
