# 설치 없이 결과물 보기

1. GitHub 저장소에서 **Code → Download ZIP**을 선택합니다.
2. 압축을 모두 풀고 이 폴더의 **index.html**을 Chrome 또는 Edge로 엽니다.
3. **새 프로젝트 만들기**로 제작·수정·복원·내려받기를 체험합니다.

화면과 글꼴이 HTML 파일 하나에 포함되어 있습니다. Node.js 설치나 서버 실행은 필요하지 않습니다.
프로젝트는 현재 브라우저에만 저장됩니다. 실제 외부 AI·고객 응답 수집·로그인·자동 외부 배포는 연결되지 않은 체험판입니다.

전체 버전은 상위 폴더의 README.md와 docs/VIEW_RESULT.md를 확인하세요.
